# Abstract

Social media platforms have become an integral part of modern communication, enabling billions of users to share information and interact globally. However, the rapid growth of these platforms has also led to the proliferation of automated accounts, commonly known as bots, which are capable of spreading misinformation, manipulating public opinion, generating spam, and conducting malicious activities at scale. Traditional bot detection methods often rely on a single type of feature, making them less effective against increasingly sophisticated bots.

FakeNet is a multi-modal bot detection framework that integrates metadata analysis, Natural Language Processing (NLP), Graph Neural Networks (GNNs), and Reinforcement Learning (RL) to improve detection accuracy and adaptability. The framework extracts profile-based metadata, analyzes textual content using NLP techniques, learns interaction patterns through graph representations, and combines these features into a unified representation for classification. Reinforcement Learning is incorporated to enable the system to adapt its detection strategy as bot behavior evolves over time.

The project utilizes publicly available benchmark datasets such as Reddit Bot Dataset, TwiBot-22, and Cresci-2017 for training and evaluation. The proposed framework aims to provide a scalable, accurate, and adaptive solution for detecting malicious automated accounts across social media platforms. Performance will be evaluated using standard classification metrics including Accuracy, Precision, Recall, F1-Score, and ROC-AUC.
