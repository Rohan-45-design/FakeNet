# Scope

## Project Scope

The FakeNet project focuses on developing a multi-modal framework for detecting bot accounts on social media platforms by combining metadata analysis, Natural Language Processing, Graph Neural Networks, and Reinforcement Learning. The system is designed to leverage publicly available benchmark datasets for training, evaluation, and performance comparison.

### In Scope

- Collection of publicly available social media bot datasets.
- Data preprocessing and feature engineering.
- Metadata feature extraction.
- Natural Language Processing for textual analysis.
- Graph Neural Network-based interaction analysis.
- Multi-modal feature fusion.
- Machine learning-based bot classification.
- Reinforcement Learning for adaptive detection strategies.
- Performance evaluation using standard classification metrics.
- Development of a modular architecture suitable for future enhancements.

### Out of Scope

- Real-time monitoring of all social media platforms.
- Detection of fake news or misinformation content.
- Human behavior prediction beyond bot detection.
- Commercial deployment at enterprise scale.
- Analysis of private or restricted social media data.
- Detection of cyberattacks unrelated to automated bot accounts.

## Expected Outcome

The expected outcome of this project is a robust, scalable, and adaptive bot detection framework capable of accurately distinguishing automated accounts from genuine users by integrating multiple feature modalities. The system aims to improve detection performance while maintaining flexibility for future research and deployment.
