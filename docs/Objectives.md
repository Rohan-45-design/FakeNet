# Objectives

The primary objective of FakeNet is to develop an accurate, scalable, and adaptive framework for detecting automated bot accounts on social media platforms using multiple sources of information.

## Specific Objectives

- Develop a unified multi-modal bot detection framework.
- Collect and preprocess benchmark social media datasets.
- Extract profile-based metadata features from user accounts.
- Analyze user-generated textual content using Natural Language Processing techniques.
- Learn user interaction patterns using Graph Neural Networks.
- Fuse metadata, NLP, and graph embeddings into a unified feature representation.
- Classify accounts as genuine users or bots using machine learning models.
- Improve the adaptability of the detection framework using Reinforcement Learning.
- Evaluate the proposed framework using standard performance metrics such as Accuracy, Precision, Recall, F1-Score, and ROC-AUC.
- Design a modular and scalable architecture that can be extended to additional social media platforms in the future.
